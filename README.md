## 📌 Overview
The **Hospital Management System** is a web-based application designed to streamline hospital operations, manage patient records, and facilitate smooth communication between doctors, staff, and patients. The system is developed using **Servlets, JSP, and MySQL** as the backend database.

## 🚀 Features
- **Patient Management**: Register, update, and view patient details.
- **Doctor Management**: Assign doctors to patients and manage schedules.
- **Appointment Scheduling**: Book, update, and cancel appointments.
- **Billing System**: Generate and manage patient bills.
- **User Authentication**: Role-based login for admin, doctors, and patients.
- **Medical Records**: Maintain history of treatments and prescriptions.
- **Admin Dashboard**: Manage hospital operations efficiently.

## 🛠️ Technologies Used
- **Backend**: Java **Servlets & JSP**
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Database**: MySQL
- **Web Server**: Apache Tomcat
- **IDE**: neatbeans

## ⚙️ Installation & Setup
### Prerequisites
- Install **Java JDK 17+**
- Install **Apache Tomcat (v9 or above)**
- Install **MySQL Server & MySQL Workbench**
- Install **Neatbeans** (Recommended IDE)

### Steps to Setup
1. **Clone the Repository**
   ```bash
   git clone https://github.com/akumar9334/Hospital_Management_System.git
   cd Hospital_Management_System
   ```
2. **Import Project into neatbeans**
3. **Configure Apache Tomcat** in your IDE
4. **Setup MySQL Database**
   - Open MySQL Workbench
   - Create a new database:
     ```sql
     CREATE DATABASE hospital_db;
     ```
   - Import the SQL file (if available) into MySQL
5. **Update Database Configuration** in `dbconfig.properties`
6. **Deploy on Tomcat Server** and Run the Application
